## Full Summary

This artifact is a reference table for testing how well the simple barometric formula predicts the boiling point of water at altitude. The table has 250 rows from two sources, each labelled by data_type. The first source is the Engineering ToolBox 'Water - Boiling Points vs. Altitude' table, taken as published: 125 rows with altitude and boiling temperature, marked computed_unknown_method because the page does not state its method. The second source is 125 IAPWS-IF97 saturation rows, computed with the iapws Python package v1.5.5 at ISA standard-atmosphere pressures for the same altitudes, marked computed_reference. The table contains zero measured rows. The planned measured sources, Osborne, Stimson and Ginnings 1939 and the CRC Handbook table, were located as NIST and other records, but their tables could not be transcribed reliably from the fetched text, so no measured row was added. The plan's rule against padding the measured set means the downstream residual test by altitude band has no measured points to report. A key check: the ToolBox values agree with IAPWS-at-ISA to within -0.31 to +1.94 K over 125 altitudes (median +0.02 K), so the benchmark is most likely computed from a standard atmosphere and is not independent evidence. Files: data.py builds full_data_out.json in the exp_sel_data_out format, grouped by source; mini_data_out.json and preview_data_out.json are the reduced variants; the table build and validation scripts sit beside them. The full file passes schema validation with zero errors and is well under the size limit.
